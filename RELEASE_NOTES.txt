LyraStage v0.18.0

- Media information now auto-saves with bounded Undo/Redo and source-reset recovery.
- Recording storage management adds per-track usage visibility, explicit cleanup, safer take handling, and cross-track copy support.
- YouTube playback uses a centered uncropped 16:9 stage over a blurred backdrop.
- Light/Dark and all five color skins were audited across the full UI; remaining fixed-theme surfaces and accent leaks were corrected.
- The default library profile icon now matches the official LyraStage application icon in both Light and Dark modes.
- Update notifications use safer defaults: automatic check ON, automatic download/apply OFF unless explicitly enabled.
- Existing settings, library data, appearance choices, and installed-edition behavior are preserved.
- v0.17.23-series in-app updater compatibility is preserved with the legacy Full/Player launcher checks.

This public release contains the existing-install update package only. The standalone first-install Setup is distributed separately.
